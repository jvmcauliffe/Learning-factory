# data/letmemaster

Parsed pages from [letmemaster.com](https://letmemaster.com) ("Let me master"), operated by Jeremy. They were fetched on 5 November 2026 under the site owner's written permission, recorded in [docs/permissions/letmemaster.md](../../docs/permissions/letmemaster.md). Please credit letmemaster.com and its owner wherever this content is used.

- Each `*.json` file holds `source_url`, `fetched_at`, `raw_sha256`, `status` and the page's headings, paragraphs, lists and tables, with the text kept as fetched.
- Everything here is a **candidate** and **unverified**. Nothing has been checked against current AWS documentation, and the pages have not been mapped to questions or lessons.
- The files are not derived from RonitSachdev/aws-saa-c03-guides (CC BY 4.0), which is credited separately in the repository README and in `content/saa-c03/ATTRIBUTION.md`.
- Raw pages and the fetch manifest are kept out of git (`raw/` is ignored).
- Written by `tools/parse_letmemaster.py`; the crawl is described in [docs/letmemaster-crawl-report.md](../../docs/letmemaster-crawl-report.md).
